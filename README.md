# CHATDOOM

Reads YouTube, Twitch, Kick and Facebook live chat aloud in Hindi, Hinglish and English, with moderation, an AI co-host,
stream tools, OBS overlays and Discord tools. Developed and powered by ZUNIMILABS.

**Download:** [CHATDOOM-Setup.exe](https://github.com/Deba-dev/ChatDoom/releases/latest/download/CHATDOOM-Setup.exe)
(Windows 10 and 11) · Website: [zunimilabs.online/chatdoom](https://zunimilabs.online/chatdoom)

This repository holds the installers only. Installed copies update themselves from its
[Releases](https://github.com/Deba-dev/ChatDoom/releases).
